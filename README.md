## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/react-class.git
```

Navigate to the project:

```bash
cd react-class
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
